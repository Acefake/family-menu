# 辅食观察

用户已批准三屏效果图，并要求严格按图实现。入口为「我的 → 辅食观察」，旁边显示当前食物及观察天数。不新增底部导航。

沿用灰蓝页头、纸白背景、宋体标题、细边框、绿色正常与琥珀色待观察。首页包含观察中/历史记录/食物档案三个Tab、进度及添加食物；不再保留最近记录和使用说明入口；打卡页包含日期、食用量、首次食用、互斥的正常/症状选项、异常时间描述及处理、备注；档案页包含搜索、三种分类、详情及导出。

数据按当前家庭保存至 uniCloud，沿用现有登录鉴权。一次仅有一种正在观察的食物；新建时选择3至5天。观察进度按实际已打卡日期计算，不能只因日历流逝而完成。症状打卡暂停观察并归入待观察；医生确认是手动记录，不自动诊断。已完成无异常记录允许修订为异常并回到待观察。

空数据明确显示空状态，示例食物不写入真实档案。保存失败留在表单并提供错误提示。重复日期覆盖原记录，事务防止家人并发覆盖。导出包含食物、日期、量、首次、症状、异常详情、处理和备注，可复制分享。

历史记录支持编辑和删除，删除前二次确认，只删除指定日期打卡并保留食物档案。编辑暂停或医生确认后的旧记录不自动解除原分类，且不允许新增试吃记录。删除和修改后重新计算连续观察进度，避免出现两种同时观察的食物。

图标采用64款橄榄绿SVG线稿并按食物名称匹配；详情弹窗区分食物摘要、观察记录和医生确认。
